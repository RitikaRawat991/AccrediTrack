# College Activity and Certification Management System

## Description

This project is a web-based system developed to manage student activities and certifications within a college. The system allows students to upload their certificates for various activities, while teachers can review and approve or reject the submitted certificates.

The application helps maintain a centralized record of student achievements and simplifies the verification process for faculty members.

## Technologies Used

* HTML
* CSS
* JavaScript
* PHP
* MySQL

## Features

* Add and manage student records
* Student login system
* Upload certificates for activities or achievements
* Teacher login system
* Certificate verification by teachers
* Accept or reject submitted certificates
* Maintain records of approved certifications

## System Modules

### Student Module

* Student registration
* Upload certificates
* View certificate status

### Teacher Module

* Teacher login
* View student submissions
* Accept or reject certificates

### Admin Module

* Manage student data
* Manage teacher accounts
* Monitor system activities
